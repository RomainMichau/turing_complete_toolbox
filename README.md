# Turing Complete Toolbox

Browser helpers for [Turing Complete](https://turingcomplete.game/): a number
converter, and the Symphony instruction set as reference, encoder and decoder.

**→ [romainmichau.github.io/turing_complete_toolbox](https://romainmichau.github.io/turing_complete_toolbox/)**

Static site — no backend, no build. It is `docs/`, served as it sits.

Same shape as [RISC-V Toolbox](https://github.com/RomainMichau/riscv-toolbox), a sibling toolbox for RV32.

```sh
npm run serve   # localhost:8080
npm test
```
